# 📊 Dashboard Financeiro & BI

Sistema de acompanhamento financeiro doméstico inteligente, projetado com interface de Business Intelligence e processamento nativo.

## 🚀 Funcionalidades
- **Gestão de Fluxo de Caixa**: Registro de receitas e despesas.
- **Gráficos Dinâmicos**: Integração com Chart.js.
- **Modo Escuro**: Conforto visual automático (Dark Mode).
- **Exportação de Dados**: Geração instantânea de planilhas CSV.
- **Armazenamento Seguro**: Persistência via LocalStorage.
